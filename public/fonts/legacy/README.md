# Fonts for the preserved editorial pages

Unmodified WOFF2 files downloaded by Next.js from Google Fonts in the successful local build on 14 November 2026. They are now served locally to avoid a Google Fonts response parsing failure in the Railway build. Font faces, subsets, weights and fallback metrics are preserved in `app/legacy-fonts.css`.

- Cormorant Garamond: https://github.com/google/fonts/tree/main/ofl/cormorantgaramond
- Karla: https://github.com/google/fonts/tree/main/ofl/karla
- La Belle Aurore: https://github.com/google/fonts/tree/main/ofl/labelleaurore

Each family is distributed under the SIL Open Font License, included alongside these files. The new landing pages use their own local Manrope files.
